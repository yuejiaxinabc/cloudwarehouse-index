Changelog

按版本聚合的变更记录，标签区分「新增 / 修复 / 优化」。

v1.4.5

Latest 稳定版 2026-11-14
  • 修复 更新时页面反复跳：构建成功后脚本在重启那步管道被打断，成功状态没写入，前端一直轮询重渲染。现在构建成功即写 success 再重启。
  • 修复 更新失败状态停在「更新中」、日志空白；成功还弹窗倒计时甚至连刷。现在失败写 failed 并回滚、日志落盘，成功静默刷新一次。
  • 修复 字典管理新增后列表不变、调拨单打印单位为 [object Object] 且缺发出/接收货位、BOM 产品不能手填、导入商品不生成序列号、导入报「货位不存在」。
  • 新增 货位封禁：整排 / 整列 / 大货位整格 / 单个小货位都能封禁与解封；大货位封禁显示淡红，小货位封禁后可用数量减少。
  • 新增 桌面端专用 API 密钥一键创建（出入库写入、商品建档、新建仓库），并给出服务器地址 / 密钥 ID / API Key 的填写说明。
  • 优化 四段货位全站统一显示；入库过账后首页与预警自动刷新；扫码支持扫码枪与摄像头自动切换；全站新 logo 与透明底圆角角标。
  • 安装 一键安装脚本支持 --channel=beta 安装测试版，默认稳定版。

v1.4.4

稳定版 2026-11-14
  • 定稿 货架模型四段编码 A-01-02-03：货架 → 第1排（横）→ 第2列（竖）→ 第3个货位；坐标是位置，位置里是统一数量的小货位。
  • 新增 货架地图重做：横轴排、纵轴列的网格，每格显示「已用小货位 / 总数」；点格看该坐标的小货位卡片，可封存 / 恢复，有库存的不能封存。
  • 调整 建仓只填四个数：货架数 / 每架几排 / 每排几列 / 每个位置几个货位，实时显示位置数与小货位总数。
  • 包含 1.4.3.x 全部修复：按通道精确更新、装完核对版本并回滚、版本列表返回数组、出库返库与退还件、回收站级联删除、撤销分权、验证码提示、Excel 金额格式、商品可选供应商、容量拦截取消等。
  • 说明 本版由 Beta 1.4.4.0 验证后转正；三位版本 = 稳定版，一键安装脚本与离线包只跟稳定版。

v1.4.3

稳定版 2026-11-13
  • 修复 切换通道报「服务器内部错误」：更新接口对已读过的请求体又调 clone，undici 抛 TypeError: unusable；现在只解析一次。
  • 优化 发布包改为 Linux 上压缩构建：源码同步到构建机用 GNU tar 打包，包内 0 个 macOS 资源叉，Linux 解压不再报异常。
  • 包含 1.4.2 全部内容：按通道精确更新、版本列表返回数组、装完核对版本并回滚、通道双向切换。

v1.4.2

稳定版 2026-11-13
  • 修复 切了测试通道却更新到主版本：自更新脚本改为按调用方传入的版本与通道精确取包，不再自行回退到通道最新版。
  • 修复 检查更新页版本列表为空 / 点不动：更新中心 /api/version 的 releases 之前返回数量而非数组，前端渲染即抛错，现已返回完整版本数组。
  • 修复 更新「假成功」：装完核对 package.json 版本，不等于目标版本即失败回滚；前端也对比目标与实际，不一致明确提示「更新未生效」。
  • 新增 通道双向切换：选 Beta 装 Beta 最新；切回主版本可装回稳定版（允许降级切换）。
  • 包含 1.4.1 系列全部内容：出库返库、退还件报表、撤销分权、回收站级联删除、货位容量拦截取消、验证码提示与可读性、出库逐行校验、草稿单作废、货架地图列多选、多项安全加固。

v1.4.1

稳定版 2026-11-13
  • 新增 出库返库：已过账的出库单也能退回未使用商品，自动生成退货入库并过账；报表中心新增「退还件」。
  • 调整 出库撤销分权：未过账有出库权限即可撤销（自动释放锁定量）；已过账仅管理员，撤销即反过账回补库存。
  • 修复 回收站彻底删除失败（按依赖顺序清理并给出具体原因）、出库单详情白屏、BOM 创建与修改参数异常、BOM 详情页 404。
  • 新增 货架地图「列」独立选择框并支持多选：按列看行、点行看货位、点货位看小货位；三级按需取数，十几万货位也不卡。
  • 安全 登出即失效、客户资料服务端消毒、Open API 建单校验可用量、上传加权限点、畸形请求返回 400。
  • 体验 更新完成自动提示并刷新；版本号显示正确；新增「接收远程更新」开关；界面蓝色主调。
  • 规则 版本号固定：三位版本（1.4.1）为稳定正版，一键安装脚本与离线包只在稳定版更新；四位版本（1.4.0.x）只作为测试版发到 Beta 通道。

v1.4.0

稳定版 2026-11-12
  • 新增 货架编码四级化：货架-列-行-货位（如 C-01-09-22），货位下再分小货位（C-01-09-22-01…）。
  • 新增 建仓规模由用户自填（几架 / 几列 / 几行 / 每行货位 / 每货位小货位数），秒建仓库、后台生成货位并显示进度，不再预生成满配。
  • 新增 扫码员角色；货架地图预热与 5 分钟缓存，按货架分批取数。
  • 新增 检查更新页可切换稳定版 / 测试版通道，按版本逐条列出改了什么。
  • 优化 一键安装脚本自动执行增量库变更（只加不删）；离线包只带 Linux 运行所需，去掉 macOS 冗余。
  • 说明 1.4.0.1 ~ 1.4.0.23 属于这一大版本的测试批次，不再单独列出。

v1.3.0

New 2026-11-12
  • 新增 设置 → API 管理：可视化创建 / 启停 / 轮换 / 删除密钥；明文只在创建时显示一次，库内只存哈希与前缀。
  • 新增 密钥支持五层约束：权限范围（scope）、仓库范围、IP 白名单、每分钟限速、有效期。
  • 新增 开放接口写能力：POST /open/stock-in 与 /open/stock-out，默认建草稿，autoPost 可选立即过账。
  • 新增 写入幂等：Idempotency-Key 24 小时内同键只执行一次，重试不会重复建单；同键换请求体返回 409。
  • 新增 写操作以密钥创建者身份执行并写审计日志，创建者停用则密钥写权限同时失效。
  • 安全 读接口按 scope 鉴权：越权 403、超限速 429、白名单外 403、密钥无效统一 401（不区分原因，防枚举）。
  • 文档 新增 api_keys 与 api_idempotency 两张表，随包自带增量 SQL，更新时自动建表、只加不删。

v1.2.0

Stable 2026-10-28
  • 新增 批次与效期台账 /inventory/lots：批次号 / 生产日期 / 到期日 / 剩余天数 / 状态，可按仓库、关键词、临期天数筛选。
  • 新增 临期自动预警：预警接口新增 expiry 类型，已过期与 ≤7 天判紧急、≤30 天判警告，预警中心加「批次临期」筛选。
  • 新增 库存冻结：批次可冻结 / 解冻，冻结量同步累加 locked（不超过在手量），解冻原样释放并写操作日志。
  • 新增 补货建议闭环：建议量 = ceil(安全库存 − 可用量) 且不超过库存上限，勾选一键生成购买申请。
  • 新增 单据附件：入库挂采购发票 / 送货单，出库挂签收回单（图片 / PDF），单张单据最多 20 个。
  • 新增 库存日结快照：每日 00:05 由 cron 落快照（幂等），可按日期回溯最近 30 个时点。
  • 新增 现场大屏 /screen：浅色看板、30 秒轮询、只读，适合仓库挂电视。
  • 新增 初始化向导 /setup：单位 → 分类 → 仓库 → 商品四步自检，带完成度进度条。
  • 新增 商品保质期与采购周期：shelfLifeDays > 0 视为效期商品，入库强制批次号 + 生产日期。
  • 新增 出库 FEFO 选批：按到期日升序逐批扣减并写拣货明细，批次不足拒绝过账，全程事务化。
  • 新增 回收站（主数据软删除 15 天可恢复）、两步验证（自研 TOTP）、登录失败递增延迟。
  • 新增 开放 API v1（products / inventory / movements，支持增量同步）与 Webhook 订阅（HMAC-SHA256 签名）。
  • 新增 SMTP 配置与报表订阅：后台可配邮件参数并自检，日报 / 周报按订阅整点发送。
  • 文档 新增《云仓用户手册 v1.2.0》（PDF，27 页）、docs/ROADMAP-v1.2.md 需求评审与 docs/UPDATE-2026-10-28.md。

v1.1.0

  • 新增 单据闭环：入库 / 出库 / 调拨 / 盘点，草稿 → 锁定 → 过账全流程与逆向处理。
  • 新增 扫码出入库、条码打印；批次、序列号与效期基础台账。
  • 新增 权限矩阵与数据范围（仓库 / 组织隔离）；操作日志与登录日志全留痕。

v1.4.0.3

Beta 2026-11-13
