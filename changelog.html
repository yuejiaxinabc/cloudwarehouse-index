Changelog

按版本聚合的变更记录，标签区分「新增 / 修复 / 优化」。

v1.3.7.2

Latest Stable 2026-11-12
  • 新增 API 调用日志与 Webhook 投递日志统一迁到「操作日志」页，作为独立页签。
  • 新增 操作日志现在有五类：系统、操作、库存、登录、API 调用、Webhook 投递，排查时一个页面看全。
  • 调整 设置里的「API 管理」「Webhook 订阅」只留配置（密钥 / 端点 / 模板），日志不再重复展示。

v1.3.7.1

Stable 2026-11-12
  • 新增 Webhook 失败重试：推送不再一次失败就丢，按 1 分钟 → 5 → 15 分钟 → 1 小时 → 6 → 24 小时退避，最多 6 次。
  • 新增 投递日志：端点、事件、状态、尝试次数、HTTP 状态码、耗时、错误原因与下次重试时间，可展开看完整报文。
  • 新增 按状态筛选（成功 / 待重试 / 已失败）、单条手动重发、「立即重试」一键扫描积压。
  • 新增 三重触发：业务事件补偿扫描、打开日志页扫描、可选外部定时任务 /api/cron/webhook-retry。
  • 优化 端点停用或删除后，其未完成投递自动判死；成功记录保留 60 天。

v1.3.7

Stable 2026-11-12
  • 新增 出库类 Webhook 模板新增「字段说明」：数量=出库出账量（库存扣减依据），领用数量=实际领用量（人员/部门台账依据），两者不一致时的取舍规则直接写进报文。
  • 新增 模板编辑页加提示，说明两个数量的用途差别，配置时不用靠猜。
  • 优化 已部署的旧系统模板启动时自动补写说明，只补缺失项、不覆盖手工调整过的内容。

v1.3.6

Stable 2026-11-12
  • 新增 Webhook 模板全部改中文键名：通知类型、单号、仓库、操作人、过账时间、商品明细，对接方直接读中文即可。
  • 新增 出库过账推送补全领用信息：领用人、领用数量、领用时间、使用部门、使用地点、班次、部门负责人。
  • 新增 入库过账推送补全：入库人、过账时间、仓库、批次号、成本价、合计数量与金额。
  • 新增 内置模板从 3 个扩到 9 个：出库完整 / 出库精简 / 出库领用视角 / 入库完整 / 库存变动 / 商品创建 / 商品更新 / 通用信封 / 默认完整。
  • 调整 移除「安全与集成」页里重复的 Webhook 管理入口，该页只保留两步验证等登录安全项。
  • 修复 设置页检查更新支持四段版本号（如 1.3.6.1）正确识别为更新。

v1.3.5

New 2026-11-12
  • 新增 Webhook 报文模板：推给对接方的 JSON 不再写死，用 {{data.orderNo}} 这类占位符自己决定字段与命名。
  • 新增 内置三个模板：默认完整报文、单据过账精简版、库存变动单商品版；系统模板可改不可删。
  • 新增 「设置 → Webhook 订阅」页面：端点管理（地址 / 事件 / 启停 / 最近推送状态）与模板管理（编辑、预览渲染）。
  • 新增 模板保存前双重校验：变量必须在白名单内、渲染后必须是合法 JSON；模板写坏时发送自动回退默认结构。
  • 修复 增量 SQL 中的 ALTER TABLE 改为幂等写法，重复更新不再报「列已存在」导致回滚。

v1.3.4.1

Fix 2026-11-12
  • 修复 创建密钥后无法复制：HTTP 访问时浏览器不提供 navigator.clipboard，改为三级降级（剪贴板 API → execCommand → 弹窗全选手动复制）。
  • 新增 开放接口调用日志：记录密钥、方法、路径、状态码、耗时、来源 IP 与错误，保留 30 天。
  • 修复 没有商品却报缺货预警：只统计商品仍存在且未删除的库存行；删除商品时清理在手为 0 的库存行。
  • 修复 版本比较支持四段（1.3.4.1 > 1.3.4），此前四段版本号被判为「已是最新」。

v1.3.4

New 2026-11-12
  • 新增 验证码签发接口限流：同 IP 每分钟 20 次，超出返回 429 并提示剩余秒数。
  • 新增 API 密钥数量上限 20 个，创建接口按 IP 每小时 10 个，列表接口每分钟 60 次。
  • 注意 密钥达到上限后新建按钮变灰并提示先清理不用的密钥；服务端同样拦截，绕过前端无效。

v1.3.2

New 2026-11-12
  • 新增 关于页新增「API 调用说明」：认证方式、权限范围、数据范围、限速与 IP 白名单、写入幂等、可用接口清单集中说明，对接方不必再来问。
  • 新增 免责与声明：自行二次开发不保障数据持久化与一致性；使用者对上传内容的版权合规自负；服务按现状提供。
  • 新增 右上角用户菜单新增「关于」入口，右侧直接显示当前版本号，点击直达设置 → 关于。
  • 新增 关于页底部直挂「服务协议」「隐私政策」入口。
  • 调整 关于页不再标注 MIT 许可，改为版权声明。

v1.3.1

New 2026-11-12
  • 新增 开放接口从 5 个扩到 14 个：新增仓库与货位、批次效期、往来单位、基础资料、单据查询（入库/出库/调拨/盘点）、库存汇总报表、密钥自检。
  • 新增 写接口：POST /open/transfer 建调拨单、POST /open/stocktake 建盘点单，均支持幂等键。
  • 新增 权限范围扩到 11 项，按「基础数据 / 仓储 / 库存 / 单据 / 写入 / 分析」分组。
  • 修复 浏览器标签页图标：补齐标准 favicon（16/32/48/64）与 apple-icon，主图标改为带透明通道的 512px，收藏夹与 iOS 桌面正常显示。
  • 修复 「API 管理」权限范围下拉为空——根因是更新脚本未执行 prisma generate，新模型在运行时不存在导致接口 500；更新器已补该步骤。

v1.3.0

New 2026-11-12
  • 新增 设置 → API 管理：可视化创建 / 启停 / 轮换 / 删除密钥；明文只在创建时显示一次，库内只存哈希与前缀。
  • 新增 密钥支持五层约束：权限范围（scope）、仓库范围、IP 白名单、每分钟限速、有效期。
  • 新增 开放接口写能力：POST /open/stock-in 与 /open/stock-out，默认建草稿，autoPost 可选立即过账。
  • 新增 写入幂等：Idempotency-Key 24 小时内同键只执行一次，重试不会重复建单；同键换请求体返回 409。
  • 新增 写操作以密钥创建者身份执行并写审计日志，创建者停用则密钥写权限同时失效。
  • 安全 读接口按 scope 鉴权：越权 403、超限速 429、白名单外 403、密钥无效统一 401（不区分原因，防枚举）。
  • 文档 新增 api_keys 与 api_idempotency 两张表，随包自带增量 SQL，更新时自动建表、只加不删。

v1.2.7

稳定基线 2026-11-11
  • 新增 更新系统：独立「更新中心」服务（零依赖单文件），登记版本 + 更新说明 + 多地域下载直链，设备侧自动比对、测速选最快线路下载、sha256 强校验、失败自动回滚。
  • 新增 双通道发布：主版本（Stable）与测试版（Beta）分开推送；每台设备各自订阅通道，测试机先验证、生产机只收正式版。
  • 新增 检查更新页改为版本列表：逐个版本显示「做了什么修改」、发布时间与包大小，由用户自己选择升级到哪一版；当前版本也有独立说明区块，无新版时显示「当前已是最新版本」。
  • 新增 侧栏版本提示：发现新版本时左下角出现「新版本 x.y.z · 立即前往更新」，点击直达设置页；在线设备每 10 分钟自动比对一次，无需刷新页面。
  • 修复 并发扣库存竞态（P0）：原「查→判断→写」改为原子条件 UPDATE；过账先做原子状态抢占。实测库存 5 被 10 单争抢由「10/10 全成功、超卖 7 件」变为「恰 5 成功 5 拒绝」，同一单并发过账 10 次由「全部通过」变为「1 通过 9 拒绝」。
  • 修复 调拨扣减、盘点结算、库存锁定/解锁同步改为原子操作；盘点结算加单据行锁，杜绝重复结算。
  • 新增 数据备份与回滚：手动/定时备份数据库 + 上传文件 + 关键配置，默认保留 30 天可调，支持下载、恢复（恢复前自动安全备份）、删除。
  • 新增 日志清空留痕：按页签清理需手输「清空日志」确认，清空动作本身写系统日志（操作人 / 时间 / 条数 / 范围）。
  • 新增 邮件模板中心：订阅必须绑定模板，正文变量按白名单渲染，禁止「填段文字就订阅」。
  • 修复 更新中心后台中文乱码（401 响应缺 charset）与页面脚本语法问题；后台管理页改为必须登录（Basic Auth）。
  • 修复 出库单明细缺少实时金额：新增每行小计与底部合计，随数量、单价即时重算。
  • 文档 新增 RELEASE-1.2.7.md 版本说明（做了什么、如何部署、后续版本策略）。

这是最后一个开源版本：此后的小步更新不再单独发包，统一通过更新中心（https://update.yuejiaxin.ln.cn）自动分发，设备联网即收通知。

v1.2.0

Latest Stable 2026-10-28
  • 新增 批次与效期台账 /inventory/lots：批次号 / 生产日期 / 到期日 / 剩余天数 / 状态，可按仓库、关键词、临期天数筛选。
  • 新增 临期自动预警：预警接口新增 expiry 类型，已过期与 ≤7 天判紧急、≤30 天判警告，预警中心加「批次临期」筛选。
  • 新增 库存冻结：批次可冻结 / 解冻，冻结量同步累加 locked（不超过在手量），解冻原样释放并写操作日志。
  • 新增 补货建议闭环：建议量 = ceil(安全库存 − 可用量) 且不超过库存上限，勾选一键生成购买申请。
  • 新增 单据附件：入库挂采购发票 / 送货单，出库挂签收回单（图片 / PDF），单张单据最多 20 个。
  • 新增 库存日结快照：每日 00:05 由 cron 落快照（幂等），可按日期回溯最近 30 个时点。
  • 新增 现场大屏 /screen：浅色看板、30 秒轮询、只读，适合仓库挂电视。
  • 新增 初始化向导 /setup：单位 → 分类 → 仓库 → 商品四步自检，带完成度进度条。
  • 新增 商品保质期与采购周期：shelfLifeDays > 0 视为效期商品，入库强制批次号 + 生产日期。
  • 新增 出库 FEFO 选批：按到期日升序逐批扣减并写拣货明细，批次不足拒绝过账，全程事务化。
  • 新增 回收站（主数据软删除 15 天可恢复）、两步验证（自研 TOTP）、登录失败递增延迟。
  • 新增 开放 API v1（products / inventory / movements，支持增量同步）与 Webhook 订阅（HMAC-SHA256 签名）。
  • 新增 SMTP 配置与报表订阅：后台可配邮件参数并自检，日报 / 周报按订阅整点发送。
  • 文档 新增《云仓用户手册 v1.2.0》（PDF，27 页）、docs/ROADMAP-v1.2.md 需求评审与 docs/UPDATE-2026-10-28.md。
