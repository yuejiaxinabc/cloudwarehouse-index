Changelog

按版本聚合的变更记录，标签区分「新增 / 修复 / 优化」。

v1.0.2

Stable 2026-10-27
  • 优化 持续打磨交互细节与系统稳定性。
  • 修复 若干缺陷修复（详见 docs/FIXLOG.md）。
  • 文档 补齐发布配套：README 重写、LICENSE、CONTRIBUTING、.github 模板。

v1.0.1

Security 2026-10-11
  • 修复 P0 移除 middleware 任意 token 头放行，/api/v1/* 改由路由内部真实校验（越权）。
  • 修复 P0 验证码答案不再下发，改为服务端 SVG 生成 + 一次性校验。
  • 修复 P1 login-check 降级空壳，统一登录 / 重置错误文案，防用户枚举。
  • 修复 P2 限流 IP 取 X-Real-IP / XFF 末段，防伪造绕过。
  • 优化 升级 next 14.2.35 / next-auth 4.24.11；移除 puppeteer-core；xlsx → exceljs。
  • 优化 关闭未使用图片优化器；CSRF 白名单移除 http 来源。

v1.0.0

Baseline 初始版本
  • 新增 8 大核心模块：商品/物料、入库、出库、库存、盘点、库位、预警、报表。
  • 新增 系统底座：RBAC、操作日志审计、API Token、NextAuth 会话认证。

更完整的变更历史见仓库 docs/CHANGELOG.md。
