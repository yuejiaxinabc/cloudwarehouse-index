Changelog

按版本聚合的变更记录，标签区分「新增 / 修复 / 优化」。

v1.4.0.23

Latest Stable 2026-11-13
  • 修复 出库单详情白屏（Application error）：返库功能的 Hook 被写在条件 return 之后，已移到组件顶部。
  • 修复 回收站彻底删除失败：按依赖顺序清理货位/库存/批次/序列号/BOM；被单据引用时给出具体原因，全程事务。
  • 安全 登出即失效（sessionVersion bump）、客户资料消毒、Open API 校验可用量、上传加权限点、畸形请求返回 400。

v1.4.0.18

Stable 2026-11-13
  • 新增 出库返库：已过账的出库单也能把未使用商品退回仓库，按行填数量与货位，自动生成退货入库单并过账。
  • 新增 报表中心「退还件」：返库单列表 + 单数/数量/金额合计。
  • 调整 出库撤销按状态分权：未过账有出库权限即可撤销（自动释放锁定量）；已过账仅管理员，撤销即反过账回补库存。
  • 修复 查看 BOM 报 404：补上 BOM 详情页，可查看与就地编辑。
  • 新增 货架地图「列」独立选择框并支持多选，按列看行、点行看货位；修复点不进去的问题。
  • 优化 界面改为蓝色主调，页脚留白加大；更新完成后自动提示并刷新，普通用户版本号不再显示旧值。

v1.4.0.8

v1.4.0.6

Stable 2026-11-13

  • 新增 建仓可按需指定货架规模（列 / 行 / 货位），不传就是 10×10×50 默认值。
  • 配套 一键安装脚本随包执行 db-changes.sql（只加不删），新列与新角色装完即到位。

v1.3.9.3

Stable 2026-11-12
  • 修复 入网服务器界面看不到域名：原来只认 NEXTAUTH_URL，很多机器那里还是 http://IP 或没配，域名就报不上去。现在按 APP_PUBLIC_URL → NEXTAUTH_URL → nginx 的 server_name → 证书目录 依次解析，只要真绑了域名就能报到更新中心。
  • 新增 安装脚本把对外地址写进 .env（APP_PUBLIC_URL / APP_DOMAIN）：绑域名写 https://域名，只走 IP 写 http://IP；老机器升级时自动补齐。
  • 修复 绑定域名但没申请证书的情况也写域名（之前只有证书成功才写）。
  • 优化 更新中心的域名列对只有 url、没有 domain 的旧数据也能反推出域名显示。

v1.3.9.2

Stable 2026-11-12
  • 修复 点「立即更新」就报「无法访问远端服务器」：自更新脚本把 .env 里的 UPDATE_HUB_URL 整串直接拼进 URL。程序侧本来就支持逗号分隔的多地址轮询，脚本却只认一个地址 —— 只要配置写成 https://…,http://…,http://127.0.0.1:9958，第一步读取更新中心元数据必然失败，页面于是弹「无法访问远端服务器」。现在脚本会把地址拆开逐个探测 /healthz，取第一个可用的，写多个、写单个、写空都能工作。
  • 优化 更新日志新增一行「更新中心: <实际地址>」，以后再遇到连不上，一眼能看出它到底在连谁。
  • 说明 已装机器若正卡在这个报错上，把 .env 的 UPDATE_HUB_URL 改成单地址 https://update.yuejiaxin.ln.cn 即可立刻恢复；升到本版本后多地址也不会再触发该问题。

v1.3.9

Stable 2026-11-12
  • 修复 无法连接远端更新：安装脚本没写更新中心地址，程序兜底去连本机 127.0.0.1:9958（多数机器上并没有更新中心），「检查更新」直接报「无法访问远端服务器」。安装脚本现在自动写入该地址，程序侧也改为按「配置项 → 公开更新中心 → 本机 9958」依次尝试，配置缺失不再必然失败。
  • 修复 点「立即更新」没反应：更新工作目录原定 /opt/cw-update-work，而服务以 cloudwarehouse 用户运行，无权在 /opt 下建目录，接口直接 500、任务永远停在 running。工作目录改到应用自己的 backups/update-work，由安装脚本创建并授权。
  • 修复 更新卡在重启：服务用户没有 systemd 权限，systemd-run 起任务、systemctl restart 自己都会被 polkit 拒绝。安装脚本现在写入最小化授权规则，只放行 cw-update-* 与 cloud-warehouse 两类 unit，卸载时一并清理。
  • 优化 安装脚本补装 rsync（更新做代码快照与失败回滚依赖它），并在结尾检测更新中心连通性，不通只提示、不阻断安装。
  • 说明 已装机器正常点「检查更新 → 立即更新」即可；若旧机器点更新仍无反应（当时没有 polkit 授权），重跑一次安装脚本补齐：curl -fsSL https://update.yuejiaxin.ln.cn/install.sh | sudo bash --upgrade。

v1.3.8

Stable 2026-11-12
  • 新增 入网心跳：装好的云仓每 5 分钟向更新中心报一次「我在」——主机名、版本、更新通道、端口、域名、系统，更新中心据此判断这台机器在线还是离线。

  • 说明 心跳只带本机随机 installId 与运行信息，不含任何业务数据、账号与密码；上报失败静默重试，不影响登录、开单与库存等主流程。
  • 配套 一键安装脚本同步升级：装完自动登记每 5 分钟一次的 systemd 定时器（无 systemd 时退回 cron），换 IP 也能自己跟上来。

  • 新增 写入幂等：Idempotency-Key 24 小时内同键只执行一次，重试不会重复建单；同键换请求体返回 409。
  • 新增 写操作以密钥创建者身份执行并写审计日志，创建者停用则密钥写权限同时失效。
  • 安全 读接口按 scope 鉴权：越权 403、超限速 429、白名单外 403、密钥无效统一 401（不区分原因，防枚举）。
  • 文档 新增 api_keys 与 api_idempotency 两张表，随包自带增量 SQL，更新时自动建表、只加不删。

v1.2.7

稳定基线 2026-11-11
  • 新增 更新系统：独立「更新中心」服务（零依赖单文件），登记版本 + 更新说明 + 多地域下载直链，设备侧自动比对、测速选最快线路下载、sha256 强校验、失败自动回滚。
  • 新增 双通道发布：主版本（Stable）与测试版（Beta）分开推送；每台设备各自订阅通道，测试机先验证、生产机只收正式版。
  • 新增 检查更新页改为版本列表：逐个版本显示「做了什么修改」、发布时间与包大小，由用户自己选择升级到哪一版；当前版本也有独立说明区块，无新版时显示「当前已是最新版本」。
  • 新增 侧栏版本提示：发现新版本时左下角出现「新版本 x.y.z · 立即前往更新」，点击直达设置页；在线设备每 10 分钟自动比对一次，无需刷新页面。
  • 修复 并发扣库存竞态（P0）：原「查→判断→写」改为原子条件 UPDATE；过账先做原子状态抢占。实测库存 5 被 10 单争抢由「10/10 全成功、超卖 7 件」变为「恰 5 成功 5 拒绝」，同一单并发过账 10 次由「全部通过」变为「1 通过 9 拒绝」。
  • 修复 调拨扣减、盘点结算、库存锁定/解锁同步改为原子操作；盘点结算加单据行锁，杜绝重复结算。
  • 新增 数据备份与回滚：手动/定时备份数据库 + 上传文件 + 关键配置，默认保留 30 天可调，支持下载、恢复（恢复前自动安全备份）、删除。
  • 新增 日志清空留痕：按页签清理需手输「清空日志」确认，清空动作本身写系统日志（操作人 / 时间 / 条数 / 范围）。
  • 新增 邮件模板中心：订阅必须绑定模板，正文变量按白名单渲染，禁止「填段文字就订阅」。
  • 修复 更新中心后台中文乱码（401 响应缺 charset）与页面脚本语法问题；后台管理页改为必须登录（Basic Auth）。
  • 修复 出库单明细缺少实时金额：新增每行小计与底部合计，随数量、单价即时重算。
  • 文档 新增 RELEASE-1.2.7.md 版本说明（做了什么、如何部署、后续版本策略）。

这是最后一个开源版本：此后的小步更新不再单独发包，统一通过更新中心（https://update.yuejiaxin.ln.cn）自动分发，设备联网即收通知。
