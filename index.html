项目简介

一套够用、好看、好上手的仓库大脑

云仓（英文代号 YUNCANG Inventory Management）是一套开源的全链路库存管理系统。它把「采购入库 → 上架库位 → 销售出库 → 盘点对账 → 预警报表」打通成一条可追溯的链路，让中小企业在不堆人的前提下，也能把仓库管得清清楚楚。

开箱即用

浏览器打开即用，无需安装客户端，私有化部署数据自主可控。

全链路追溯

从入库到出库每一步可查，批次、库位、操作人全记录。

安全合规

三重安全审计 + 6 项核心安全机制，高危漏洞已清零。

移动协同

配套微信小程序端，仓管员手机即可扫码作业。

适用行业

制造业 零售连锁 贸易批发 电商 医疗器械 食品生鲜 五金建材 汽车零部件

产品功能

核心 8 大模块

从商品建档到成本结转，每个环节都可追溯、可审计、可预警。

商品 / 物料管理

SKU、分类体系、单位换算、规格属性、条码与供应商关联。

入库管理

采购 / 退货 / 生产 / 其他入库，支持扫码入库、批次与效期。

出库管理

销售 / 领料出库、审批流程，乐观锁防超卖。

库存查询

实时结存、可用量（on_hand − locked）、库位明细与批次追踪。

盘点管理

全盘 / 循环盘点，差异自动调整，账实一致有保障。

仓库库位

多仓库，区域→货位→盒子三级库位，货架地图与移库调拨。

预警中心

低库存 / 高库存 / 临期 / 呆滞，四类自动预警。

报表统计

收发存、周转率、库龄，移动加权 / FIFO 成本核算。

扩展能力

BOM 物料清单 序列号追踪 条码标签打印 Excel 导出（exceljs） 📱 微信小程序端 ↗
RBAC 用户角色权限
操作日志 审计追踪
API Token 开放接口
NextAuth 会话认证

安全日志

安全，是仓库数据的底线

项目经过「黑盒实测 + 代码审查 + 依赖扫描」三重安全审计。v1.0.1 已修复全部已发现的高危问题，并持续披露。

密码哈希

bcrypt(12) 强哈希存储，明文永不落库。

参数化查询

Prisma ORM 全程参数化，杜绝 SQL 注入。

CSRF 防护

Origin 校验 + 白名单，跨站请求被拦截。

接口限流

基于真实客户端 IP 限流，防爆破与滥用。

安全响应头

HTTPS / HSTS / CSP 全量启用。

库存乐观锁

并发出库防超卖，账实一致。

已修复漏洞清单 · FIX-2026-1001~1006

编号 级别 问题 修复方案
1001 P0 middleware 任意 token 头放行导致越权 移除放行逻辑，/api/v1/* 由路由内部真实校验
1002 P0 验证码答案随前端下发可被绕过 服务端 SVG 生成 + 一次性校验，答案不下发
