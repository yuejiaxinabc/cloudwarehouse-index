Linux 一键部署

两条命令
装完就能用

纯净系统也行。在线安装一条命令：环境检测 → 下载运行时包 → 建库建表 → 起服务 → 配反代。
离线安装下载同一个包，解压执行即可，全程不联网。

在线安装

需要联网，一条命令

脚本先做环境检测（缺什么装什么），再下载预构建运行时包解压部署，不需要在服务器上 npm install 或编译。约 2 分钟。

curl -fsSL https://update.yuejiaxin.ln.cn/install.sh | sudo bash

最短写法：curl -fsSL https://update.yuejiaxin.ln.cn/i | sudo bash

无人值守带域名：curl -fsSL https://update.yuejiaxin.ln.cn/install.sh | sudo bash -s -- --domain=wms.example.com

跳过域名交互加 --no-domain；已装机器升级加 --upgrade

离线安装

无需联网，适合内网 / 无外网服务器

包内已含构建好的运行时（Next standalone + Prisma 引擎 + 建表 SQL），服务器上不需要 npm install，也不需要访问外网。约 2 分钟。离线模式不申请 SSL 证书（无外网签不了），需要时联网后执行 certbot --nginx -d 域名 补上。

wget https://updata-1307293667.cos.ap-beijing.myqcloud.com/cloudwarehouse-offline-1.3.7.5.tar.gz
tar xzf cloudwarehouse-offline-1.3.7.5.tar.gz && sudo bash cloudwarehouse/install.sh --offline

卸载

装错了或想重来

停止并移除服务、清掉 nginx 配置、删除应用目录。数据库默认保留（重装可直接复用），加 --purge 才会连库一起删。

curl -fsSL https://update.yuejiaxin.ln.cn/uninstall.sh | sudo bash

最短写法：curl -fsSL https://update.yuejiaxin.ln.cn/u | sudo bash

保留数据库静默卸载：... | sudo bash -s -- --keep-data --yes　连库删除：--purge --yes

卸载会做什么 / 不会做什么

  • 会：停服务、删 systemd unit、删 nginx 站点配置、删应用目录、删系统用户。
  • 不会：不动 Node / MySQL / nginx 这些依赖（可能被其它应用共用）。
  • 默认保留：数据库 warehouse 与 .env，并会把 .env 备份到 /root/。

环境检测优先

先检查 Node / 数据库 / nginx，缺什么装什么；都齐了就直接部署最新代码，不重复折腾。

域名与 SSL 都可选

安装开始就问是否绑定域名；绑了之后再问是否申请免费 HTTPS 证书。跳过域名则应用直接映射到 80 端口。

也可参数化

无人值守时用 --domain=wms.example.com 或 --no-domain 跳过交互。

可重复执行

已装过的机器再跑一次等于升级：保留数据库、.env、备份与上传文件，只替换代码。

安装脚本会做什么

识别系统

Ubuntu / Debian / CentOS / RHEL / Rocky / Alma / Fedora，自动选包管理器

装齐依赖

Node 20、MySQL 或 MariaDB、nginx、curl 等基础组件

建库建表

创建库与专用账号，导入 67 张表结构，不写入任何演示数据

随机密钥

NEXTAUTH_SECRET 与数据库密码现场生成，写入 600 权限的 .env

守护进程

systemd 服务 cloud-warehouse，崩溃自动重启，开机自启

反向代理

nginx 反代到 127.0.0.1:3000，预留 ACME 目录方便加 HTTPS

装完之后

访问

http://服务器IP 或你传入的域名

初始账号

admin / Admin@123，登录后立即改密

管理服务

systemctl status cloud-warehouse

看日志

journalctl -u cloud-warehouse -f

加 HTTPS

certbot --nginx -d 你的域名（扫码等功能需要 HTTPS）

数据库密码

见 /opt/cloud-warehouse/.env（600 权限）

两个前提

  • 系统要求：64 位 Linux，内存 ≥ 2 GB，磁盘 ≥ 10 GB，root 权限。
  • 端口占用：80 端口给 nginx，3000 给应用。脚本会覆盖已有的 /etc/nginx 中同名配置，但不会动其它站点。
