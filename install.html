Linux 部署安装 · v1.3.7.5

一条命令，
装到干净的服务器

不用先装 Node、不用手动建库、不用碰 nginx。命令跑完就能打开浏览器登录：环境检测 → 装依赖 → 建库建表 → 起服务 → 配反代，约 2 ~ 5 分钟。内网机器也有离线包。

在线安装 离线安装 卸载 装完之后

装之前先看：硬性要求

  • 内存 ≥ 4 GB：源码安装要跑 npm install + next build，实测 4 GB 以下会 OOM 或极慢。脚本会检测，不够直接终止并提示。
  • 系统：64 位 Linux（Ubuntu / Debian / CentOS / RHEL / Rocky / Alma / Fedora）。
  • 磁盘 ≥ 20 GB：源码 + 依赖 + 构建产物约 3 GB，数据库另算。
  • root 权限：会写 /opt、/etc/systemd、/etc/nginx。
  • 内存不足的出路：改用离线包，不编译，装机更快。
推荐 · 在线安装

需要联网，一条命令

在刚装好的 Linux 上执行，脚本先做环境检测（缺什么装什么），再下载预构建运行时包解压部署 —— 不需要在服务器上 npm install，也不需要编译。

$ curl -fsSL https://update.yuejiaxin.ln.cn/install.sh | sudo bash

已是 root 可以去掉 sudo；服务器没有 curl 时，把 curl -fsSL 换成 wget -qO-。

无人值守绑域名：在命令末尾加 -s -- --domain=wms.example.com，脚本会一并申请免费 HTTPS。

跳过域名交互加 --no-domain；已装过的机器原地升级加 --upgrade（保留数据库与配置）。

系统要求64 位 Linux · ≥ 4 GB 内存 · ≥ 20 GB 磁盘
权限root（sudo）
端口80 / 443 给 nginx，3000 给应用
预计耗时2 ~ 5 分钟

适用发行版：Ubuntu 20.04+ / Debian 11+ / CentOS 7+ / RHEL / Rocky / Alma / Fedora，脚本自动识别包管理器（apt / dnf / yum）。

离线安装

没有外网 / 内存不足时走这条

包内已含构建好的运行时（Next standalone + Prisma 引擎）+ Node 20 运行时 + 建表与初始数据 SQL。 目标机不需要 npm install、不需要编译、不需要外网。

文件名cloudwarehouse-offline-1.3.7.5.tar.gz
体积81 MB
SHA256f61dbbae…af2687
内含 Nodev20.18.1 x64

用 U 盘导入，四步完成

1
在能上网的电脑上下载这个包
$ curl -O https://updata-1307293667.cos.ap-beijing.myqcloud.com/cloudwarehouse-offline-1.3.7.5.tar.gz

Windows / Mac 也可以直接用浏览器打开这个地址下载。下载后拷进 U 盘。

2
把 U 盘插到目标服务器，找到并挂载它
$ lsblk # 看新增的是 sdb 还是 sdc
$ mkdir -p /mnt/usb && mount /dev/sdb1 /mnt/usb # sdb1 换成实际分区

U 盘是 NTFS 格式时改用：mount -t ntfs-3g /dev/sdb1 /mnt/usb（需先 apt install ntfs-3g）

3
把包复制到服务器并解压
$ cp /mnt/usb/cloudwarehouse-offline-1.3.7.5.tar.gz /root/ && cd /root && tar xzf cloudwarehouse-offline-1.3.7.5.tar.gz

建议先校验：sha256sum cloudwarehouse-offline-1.3.7.5.tar.gz，应等于 f61dbbae…af2687

4
执行安装
$ sudo bash cloudwarehouse/install.sh --offline

过程中同样会问域名（回车跳过即可），约 2 分钟完成。装完可用 umount /mnt/usb 拔盘。

离线安装仍需注意

  • 数据库要能装：包里不含 MySQL/MariaDB。目标机需能访问内网 apt/yum 源，或已预装（mysqld／mariadbd 在 PATH 里）。
  • 不申请 SSL 证书：离线环境无法完成域名验证，需要 HTTPS 时联网后执行 certbot --nginx -d 你的域名。
  • 内存 ≥ 4 GB：与在线安装一致；这条路不编译，所以启动更快。
卸载

装错了或想重来

停止并移除服务、删 nginx 站点配置、删应用目录。数据库默认保留（重装可直接复用），加 --purge 才会连库一起删。

$ curl -fsSL https://update.yuejiaxin.ln.cn/uninstall.sh | sudo bash

保留数据库静默卸载：curl -fsSL https://update.yuejiaxin.ln.cn/uninstall.sh | sudo bash -s -- --keep-data --yes

连库一起删（不可恢复）：curl -fsSL https://update.yuejiaxin.ln.cn/uninstall.sh | sudo bash -s -- --purge --yes

卸载会做什么 / 不会做什么

  • 会：停服务、删 systemd unit、删 nginx 站点配置、删应用目录、删系统用户。
  • 不会：不动 Node / MySQL / nginx 这些依赖（可能被其它应用共用）。
  • 默认保留：数据库 warehouse 与 .env，并把 .env 备份到 /root/。

环境检测优先

先查 Node / 数据库 / nginx，缺什么装什么；都齐了就直接部署，不重复折腾。

域名与 SSL 可选

绑了域名就问是否申请免费 HTTPS；跳过则应用直接映射到 80 端口。

也可参数化

无人值守用 --domain= 或 --no-domain 跳过交互。

可重复执行

已装过的机器再跑一次等于升级：保留数据库、.env、备份与上传文件，只替换代码。

脚本会做什么

识别系统

Ubuntu / Debian / CentOS / RHEL / Rocky / Alma / Fedora，自动选包管理器

装齐依赖

Node 20、MySQL 或 MariaDB、nginx、certbot 等，缺什么补什么

建库建表

创建库与专用账号，导入 67 张表结构，不写入任何演示数据

随机密钥

NEXTAUTH_SECRET 与数据库密码现场生成，写入 600 权限的 .env

守护进程

systemd 服务 cloud-warehouse，崩溃自动重启，开机自启

反向代理

nginx 反代到 127.0.0.1:3000，停用默认站点，预留 ACME 目录

装完之后

访问

http://服务器IP 或你传入的域名

初始账号

admin / Admin@123，登录后立即改密

管理服务

systemctl status cloud-warehouse

看日志

journalctl -u cloud-warehouse -f

加 HTTPS

certbot --nginx -d 你的域名（扫码等功能要求 HTTPS）

数据库密码

见 /opt/cloud-warehouse/.env（600 权限）

两个前提

  • 系统要求：64 位 Linux，内存 ≥ 4 GB，磁盘 ≥ 20 GB，root 权限。
  • 端口占用：80 给 nginx、3000 给应用。脚本会覆盖 /etc/nginx 下同名站点配置，但不动其它站点。
