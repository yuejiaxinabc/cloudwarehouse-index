隐私政策 / Privacy Policy

最后更新：2026-11-15

一、我们收集什么

云仓（服务端与桌面客户端）不收集、不上传任何用户数据：没有埋点、没有崩溃上报、没有账号体系外的第三方统计。 桌面客户端只保存本地配置（服务器地址与 API 密钥，密钥用 Windows DPAPI 加密）与运行日志。

二、数据保存在哪

商品、库存、单据等业务数据全部保存在你自己部署的云仓服务器上；桌面客户端只通过 HTTP API 读写这些数据，不在本地留副本。 卸载客户端时会一并删除本地配置与缓存。

三、代码签名

云仓桌面安装包使用 SignPath Foundation 提供的免费开源项目代码签名服务完成签名， 证书由 SignPath Foundation 签发。签名只用于证明安装包来源与完整性，不涉及任何数据传输。

四、联系方式

问题与数据删除请求：通过 GitHub Issues 提交。
