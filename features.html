产品功能

核心 8 大模块

8 大核心模块 + v1.2.0 新增的批次效期、补货闭环与现场能力，从商品建档到成本结转，每个环节都可追溯、可审计、可预警。

商品 / 物料管理

SKU、分类体系、单位换算、规格属性、条码与供应商关联；保质期（天）与采购周期可维护，决定是否走效期策略。

入库管理

采购 / 退货 / 生产 / 其他入库，扫码收货；效期商品强制批次号 + 生产日期，到期日自动推算并写入批次台账。

出库管理

销售 / 领料出库、审批流程，乐观锁防超卖；FEFO 先到期先出逐批扣减，拣货明细（outbound_lot_picks）可追溯。

库存查询

实时结存、可用量（on_hand − locked）、库位与批次明细；库存分析页提供账实对账 / 呆滞库龄 / ABC / 补货建议。

盘点 / 调拨

全盘 / 循环盘点，差异自动调整并留痕；跨仓调拨（发出 → 接收）闭环，账实一致有保障。

仓库与货位

多仓库；建仓自动生成 A–Z 26 货架 × 100 货位；四段货位编码（区-排-列-位），货架地图可视上架，一个货位一个商品。

预警与补货

缺货 / 低库存 / 高库存价值 / 批次临期四类自动预警，补货建议可一键转购买申请。

报表与分析

收发存、周转、库龄、成本报表；每日 00:05 库存日结快照可回溯任意时点，支持邮件日报 / 周报订阅。

v1.2.0 新增

批次效期 · 补货闭环 · 现场能力

基线 v1.1.1，v1.2.0 一次覆盖七项：批次与效期一等公民、补货闭环、库存冻结、单据附件、日结快照、现场大屏、初始化向导。

批次与效期台账

新增 /inventory/lots 与 GET /api/inventory/lots：批次号 / 生产日期 / 到期日 / 剩余天数 / 状态，支持仓库、关键词、临期天数筛选。

临期预警与库存冻结

预警接口新增 expiry 类型：已过期 / ≤7 天判紧急、≤30 天判警告；批次可一键冻结 / 解冻，冻结量同步计入 locked 并写操作日志。

补货建议闭环

建议量 = ceil(安全库存 − 可用量)，且不超过库存上限；预警中心勾选即生成购买申请（同名同仓已有 PENDING 自动跳过）。

单据附件

attachments 表 + /api/attachments：入库挂采购发票 / 送货单，出库挂签收回单，单张单据最多 20 个，沿用魔数校验与随机文件名。

现场大屏

独立路由 /screen：白底大字看板，KPI / 近 7 天出入库柱图 / 预警滚动 / 实时时钟，30 秒轮询、只读，适合挂电视。

库存日结快照

inventory_snapshots + 幂等 POST /api/snapshots/run；服务器 cron 每天 00:05 落快照，可按日期回溯最近 30 个时点。

初始化向导

/setup 四步自检（单位 → 分类 → 仓库 → 商品），带完成度进度条与跳转入口，新环境几分钟配好主数据。

SMTP 与报表订阅

后台可配 host / port / SSL·STARTTLS / 发件账号，保存即生效、密码回读脱敏；支持测试连接与真发测试邮件，日报 / 周报按订阅发送。

回收站与两步验证

主数据删除改软删除进回收站，15 天可恢复；自研 RFC6238 TOTP 两步验证，开启后登录需额外 6 位动态码；登录失败递增延迟不锁号。
