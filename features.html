产品功能

核心 8 大模块

从商品建档到成本结转，每个环节都可追溯、可审计、可预警。

商品 / 物料管理

SKU、分类体系、单位换算、规格属性、条码与供应商关联，商品档案一处维护全局可用。

入库管理

采购 / 退货 / 生产 / 其他入库，支持扫码收货、批次与效期登记，自动生成入库单。

出库管理

销售 / 领料出库、审批流程，乐观锁防超卖，准确扣减每一笔库存。

库存查询

实时结存、可用量（on_hand − locked）、库位明细与批次追踪，随时知道货在哪。

盘点管理

全盘 / 循环盘点，差异自动调整并留痕，账实一致有保障。

仓库库位

多仓库管理，区域→货位→盒子三级库位，货架地图可视上架与移库调拨。

预警中心

低库存 / 高库存 / 临期 / 呆滞，四类自动预警，问题货早发现早处理。

报表统计

收发存、周转率、库龄报表，移动加权 / FIFO 成本核算，决策有据。

扩展能力

BOM 物料清单 序列号追踪 条码标签打印 Excel 导出（exceljs） 📱 微信小程序端 ↗

系统底座

RBAC 用户角色权限
操作日志 审计追踪
API Token 开放接口
NextAuth 会话认证

适用行业

制造业 零售连锁 贸易批发 电商 医疗器械 食品生鲜 五金建材 汽车零部件
