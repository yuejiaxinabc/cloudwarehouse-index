版本发布

发布时间线

每一次发布都可追溯、可回看。安全相关版本均经过独立审计。

v1.3.7.2

Latest Stable 2026-11-12

基线 v1.3.7.1。日志归日志，配置归配置。

  • 统一入口：API 调用与 Webhook 投递都进「操作日志」页签。
  • 配置收敛：设置页只管密钥、端点与模板。

v1.3.7.1

Stable 2026-11-12

基线 v1.3.7。Webhook 从「发一次算一次」变成「有记录、会重试、能补发」。

  • 失败重试：六级退避，最多 6 次；端点停用即判死，不做无意义重试。
  • 投递日志：状态 / 次数 / HTTP / 耗时 / 错误 / 下次重试一目了然，可展开看报文。
  • 手动补发：单条重发与「立即重试」批量扫描。

v1.3.7

Stable 2026-11-12

基线 v1.3.6。把「数量」与「领用数量」的取舍规则写进报文，减少对接时的来回确认。

  • 字段说明：出库模板自带说明——数量做出账、领用数量做台账。
  • 编辑提示：模板配置页直接标注两个数量的用途。
  • 平滑升级：旧系统模板只补缺失说明，不动你改过的内容。

v1.3.6

Stable 2026-11-12

基线 v1.3.5。Webhook 报文改成中文，出库推送带齐「谁取的、何时、多少」。

  • 中文键名：通知类型 / 单号 / 仓库 / 操作人 / 过账时间 / 商品明细。
  • 领用信息：出库推送补齐领用人、领用数量、领用时间、部门、地点、班次。
  • 9 套模板：出库完整 / 精简 / 领用视角 / 入库完整 / 库存变动 / 商品创建 / 商品更新 / 通用信封 / 默认。
  • 去重：「安全与集成」页不再重复管理 Webhook，统一收口到设置。

v1.3.5

Stable 2026-11-12

基线 v1.3.4.1。Webhook 终于能「按对方要的格式推」了。

  • 报文模板化：推送 JSON 由模板决定，{{data.orderNo}} 这类占位符自由选字段与命名。
  • 内置三模板：默认完整报文 / 单据过账精简版 / 库存变动单商品版；系统模板可改不可删。
  • 管理页：设置 → Webhook 订阅，端点与模板一处管理，支持预览渲染。
  • 双重校验：变量白名单 + 渲染后必须合法 JSON；模板写坏时自动回退默认结构，不影响对方接收。

v1.3.4.1

Fix 2026-11-12

修三个实际使用中暴露的问题，并补上调用日志。

  • 密钥复制：HTTP 下 navigator.clipboard 不可用，改为三级降级复制。
  • 调用日志：记录密钥、路径、状态码、耗时、来源 IP，保留 30 天。
  • 幽灵预警：只统计未删除商品的库存行，删商品时清理零库存行。
  • 四段版本：支持 1.3.4.1 这类版本号比较。

v1.3.4

New 2026-11-12

把限流补齐到「签发票据」和「密钥管理」这两处之前遗漏的地方。

  • 验证码签发：同 IP 每分钟 20 次。
  • 密钥配额：总量 20 个，创建每小时 10 个，列表每分钟 60 次。

v1.3.2

Stable 2026-11-12

基线 v1.3.1。这一版把「对外对接」讲清楚：能力边界、调用方式、免责边界都写在系统里。

  • API 调用说明：关于页集中说明认证方式、权限范围、数据范围、限速与 IP 白名单、写入幂等、可用接口清单。
  • 免责与声明：自行二次开发不保障数据持久化与一致性；使用者对上传内容的版权合规自负；服务按现状提供。
  • 关于入口：右上角用户菜单新增「关于」，右侧显示当前版本号；页脚直挂服务协议与隐私政策。
  • 许可表述：关于页不再标注 MIT，改为版权声明。

v1.3.1

New 2026-11-12

基线 v1.3.0。开放接口补齐到 14 个，并修掉两个真实缺陷。

  • 接口扩充：新增仓库与货位、批次效期、往来单位、基础资料、单据查询、库存汇总报表、密钥自检；写接口增加调拨与盘点。
  • 权限细化：scope 扩到 11 项，按基础数据 / 仓储 / 库存 / 单据 / 写入 / 分析分组。
  • 图标修复：补齐 favicon（16/32/48/64）与 apple-icon，主图标改透明通道 512px。
  • 更新器修复：构建前补 prisma generate，避免新增模型导致接口 500、页面下拉框空白。

v1.3.0

New 2026-11-12

基线 v1.2.7。首次提供完整的 API 密钥体系与对外开放写能力。

  • API 管理：可视化建密钥，明文只显示一次；五层约束（scope / 仓库 / IP / 限速 / 有效期）。
  • 写入能力：POST /open/stock-in、/open/stock-out，默认草稿，可选自动过账。
  • 幂等：Idempotency-Key 24 小时内同键只执行一次，重试不重复建单。
  • 审计：写操作以密钥创建者身份执行并记日志，创建者停用即失去写权限。

v1.2.7

稳定基线 2026-11-11

基线 v1.2.6。这是最后一个开源版本，此后的小步更新统一由更新中心自动分发。

  • 更新系统：独立更新中心登记版本、更新说明与多地域下载直链；设备自动比对、测速选最快线路、sha256 强校验、失败自动回滚。
  • 主版本 / 测试版双通道：生产机只收 Stable，验证机可切 Beta 先验证；同一中心可同时推两套版本。
  • 多版本自选升级：检查更新页按版本列出「这个版本改了什么」，由用户自己选择升到哪一版；无新版显示「当前已是最新版本」。
  • 并发扣库存原子化：库存 5 被 10 单争抢由「全部成功、超卖 7 件」变为「恰 5 成功」；同一单并发过账由「10 次全过」变为「1 次通过」。
  • 备份与回滚 / 日志留痕：库 + 上传文件 + 配置定时备份，默认留 30 天；清空日志需手输确认且自动留痕。
  • 说明文档：RELEASE-1.2.7.md（做了什么、如何部署、后续版本策略）。

v1.2.0

Stable 2026-10-28

基线 v1.1.1。一次版本覆盖七项：批次与效期、补货闭环、库存冻结、单据附件、日结快照、现场大屏、初始化向导。

  • 批次与效期：批次台账 /inventory/lots、临期自动预警（≤7 天紧急 / ≤30 天警告）、批次冻结与解冻。
  • FEFO 先到期先出：出库按到期日升序逐批扣减，写拣货明细；效期商品批次不足直接拒绝过账。
  • 补货闭环：补货建议一键转购买申请，打通「预警 → 补货 → 入库」。
  • 单据附件 / 日结快照 / 现场大屏 / 初始化向导：附件挂发票与回单；每日 00:05 快照可回溯；/screen 大屏 30 秒轮询；/setup 四步自检。
  • 系统能力：回收站（15 天可恢复）、两步验证（TOTP）、登录递增延迟、开放 API v1、Webhook（HMAC-SHA256）、SMTP 与报表订阅。
  • 详见 docs/CHANGELOG.md 与 docs/ROADMAP-v1.2.md。
