v1.0.1

Security 2026-10-11

修复安全审计发现的漏洞 FIX-2026-1001~1006，含两处 P0 高危项，并升级关键依赖。

  • 移除 middleware 任意 token 头放行（P0 越权）。
  • 验证码改为服务端 SVG 生成 + 一次性校验（P0）。
  • 依赖升级：next 14.2.35 / next-auth 4.24.11；移除 puppeteer-core；xlsx → exceljs。
