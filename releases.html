版本发布

发布时间线

每一次发布都可追溯、可回看。安全相关版本均经过独立审计。

v1.4.3

Latest 稳定版 2026-11-13

切通道不再 500，发布包改为 Linux 原生打包。

  • 切通道 500 修复：请求体只解析一次。
  • Linux 打包：GNU tar 产出，0 个 macOS 资源叉。

v1.4.2

稳定版 2026-11-13

更新链路彻底修复：按通道精确更新、版本校验、失败回滚，通道可双向切换。

  • 按通道更新：选 Beta 装 Beta，切回主版本装回稳定版。
  • 版本列表修复：/api/version 的 releases 返回数组，不再点不动。
  • 假成功修复：装完核对版本号，不符即回滚并提示。
  • 含 1.4.1 系列全部修复（返库、退货报表、回收站、容量拦截、验证码等）。

v1.4.1

稳定版 2026-11-13

1.4.0 系列的第一个稳定正版。三位版本为正式版；四位版本只作为测试版走 Beta 通道，稳定版才更新一键安装脚本与离线包。

  • 出库返库：已过账也能退回未使用商品；报表中心新增「退还件」。
  • 撤销分权：未过账有出库权限即可撤，已过账仅管理员（反过账）。
  • 修复：回收站彻底删除、出库单详情白屏、BOM 参数异常与 404。
  • 货架地图：列多选、按行看货位、三级按需取数。
  • 安全：登出即失效、资料消毒、可用量校验、上传权限点。

v1.4.0

稳定版 2026-11-12

货架编码四级化 + 建仓规模自填。

  • 货架-列-行-货位四级编码，货位下再分小货位。
  • 建仓按用户填写的架 / 列 / 行 / 货位数生成，秒建并显示进度。
  • 新增扫码员角色；更新通道可切稳定版 / 测试版。

v1.3.0

New 2026-11-12

基线 v1.2.7。首次提供完整的 API 密钥体系与对外开放写能力。

  • API 管理：可视化建密钥，明文只显示一次；五层约束（scope / 仓库 / IP / 限速 / 有效期）。
  • 写入能力：POST /open/stock-in、/open/stock-out，默认草稿，可选自动过账。
  • 幂等：Idempotency-Key 24 小时内同键只执行一次，重试不重复建单。
  • 审计：写操作以密钥创建者身份执行并记日志，创建者停用即失去写权限。

v1.2.0

Stable 2026-10-28

基线 v1.1.1。一次版本覆盖七项：批次与效期、补货闭环、库存冻结、单据附件、日结快照、现场大屏、初始化向导。

  • 批次与效期：批次台账 /inventory/lots、临期自动预警（≤7 天紧急 / ≤30 天警告）、批次冻结与解冻。
  • FEFO 先到期先出：出库按到期日升序逐批扣减，写拣货明细；效期商品批次不足直接拒绝过账。
  • 补货闭环：补货建议一键转购买申请，打通「预警 → 补货 → 入库」。
  • 单据附件 / 日结快照 / 现场大屏 / 初始化向导：附件挂发票与回单；每日 00:05 快照可回溯；/screen 大屏 30 秒轮询；/setup 四步自检。
  • 系统能力：回收站（15 天可恢复）、两步验证（TOTP）、登录递增延迟、开放 API v1、Webhook（HMAC-SHA256）、SMTP 与报表订阅。
  • 详见 docs/CHANGELOG.md 与 docs/ROADMAP-v1.2.md。

v1.1.0

首个稳定基线：单据闭环、扫码、权限矩阵。

  • 权限矩阵与数据范围、操作与登录日志。
